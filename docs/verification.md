# 验证范围

本文区分历史验收与当前开源清理检查。历史原始截图、账号信息、任务 ID 和部署日志保存在本地私有材料中，不随源码公开，也不能用它们推定当前设备在线或模型可用。

## 历史验证（2026-10-10 至 2026-10-13）

| 能力 | 已有记录 | 边界 |
|---|---|---|
| Android 基础控制 | Huawei nova 10 / HarmonyOS 4.2 / Android 12 的截图、点击、滑动、中文输入、文件传输 | 其他机型 / 系统需重测 |
| Codex CLI | 设置搜索任务与单图小红书草稿 | 有暂停、修复、恢复和人工收尾，不是无人值守稳定性评测 |
| 小红书草稿 | 单图编辑、保存、草稿列表、重开标题 / 正文核对 | 未验收公开发布、多图顺序或跨账号切换 |
| USB | ADB reverse 自动维护与移除隧道后的恢复 | USB 调试与 Portal 权限需实际授权 |
| 局域网 WS | 无 USB reverse 时截图和原生图库能力查询 | 测试时 USB 线仍用于配置；未验证物理拔线后的系统省电行为 |
| Portal 原生图库 | 独立扩展 APK 的 PNG / JPEG 扫描 | 扩展 APK 未包含在本仓库；不能假设官方 APK 等价 |
| WorkBuddy CLI | 未登录提示识别和固定错误返回 | 真实视觉、结构化动作及手机闭环未验收 |
| 微信 / 获客模板 | UI、业务约束、模拟设备 / 模型和数据库集成测试 | 未验收真实微信发送、好友申请或小红书评论 |
| 素材生成 | 中文 PNG、图片合成 MP4；AI 适配器模拟响应 | 未调用真实外部 AI 图片 / 视频服务 |
| 归档与回放 | 自动化测试及模拟 API 浏览器检查 | 不代表真实手机任务已完成 |

WSS、公网 TLS 代理、Docker Compose 部署、备份恢复、多实例和长期运营可靠性尚未在本次环境验收。

## 本地测试

```sh
make test
make vet
cd frontend
npm ci
npm test
npm run build
```

未设置 `TEST_DATABASE_URL` 时数据库集成测试会跳过。需要集成测试时，准备专用 PostgreSQL，账号具备创建数据库权限，再在私有环境中设置该变量并运行 `make test`。各测试创建并删除独立的 `mobile_test_*` 数据库；不要使用生产实例做测试。

设备测试使用模拟 Portal 和模拟模型，CLI 测试使用本地假进程，不需要连接真实手机或模型账号。`model-probe` 和工作台模型测试会发起真实模型调用，不属于默认离线测试。
