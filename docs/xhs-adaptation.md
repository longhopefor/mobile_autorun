# 小红书业务适配与草稿验收

更新：2026-10-10。当前实测为 Huawei nova 10（HarmonyOS 4.2 / Android API 31）、Portal v0.7.25、小红书 8.64.0。本轮以本机 Codex CLI 作为视觉模型，生成并保存一张配图的草稿，未公开发布。

## 实现链路

Vue 工作台 → Gin API → PostgreSQL/River → Eino Agent → 小红书适配器 → Portal 手机执行端。模型仍可通过 API、Codex CLI 或 WorkBuddy CLI 适配，只有本机 Codex 在本轮完成真实手机验证。

小红书固定流程由 `internal/business/xhs.go` 处理。已知控件通过无障碍资源 ID、文字或描述定位；未标识的图片选择圈交给视觉模型，并附本任务参考图。规则决策单独记录 `rule_decision`，不会伪装为模型调用。

| 阶段 | 实际检查与动作 |
|---|---|
| account | 打开个人页，读取账号名称/小红书号，与任务指定值匹配；已有编辑器未确认账号时请求接管 |
| media | 文件上传后逐字节读回；图库索引；选择任务 UUID 独立相册，视觉选择图片，观察下一步(N)确认数量 |
| compose | 聚焦正确标题/正文输入框后输入指定内容；观察两个真实字段全文匹配 |
| save | 先收起键盘；点击命名保存控件；记录保存意图再发送动作 |
| verify_draft | 定位原生保存确认弹窗的“确定”；进入草稿列表，必须同时见到草稿页标识和目标标题 |
| reopen | 重开目标草稿，读取并精确核对标题和正文 |
| complete | 提交截图和业务证据作为完成候选，保留人工最终核验 |

业务状态和对应事件同事务保存到 PostgreSQL `business_progress`，包含账号观察、素材数量、内容观察、保存/确认意图、列表/重开结果和最终观察 ID。迁移由内嵌 SQL 文件依序执行并记录版本，启动迁移通过事务锁串行化。

## 控件与执行保护

命名点击执行前重新观察：要求前台包名、Activity、屏幕尺寸、目标属性与边界保持相同，且控件唯一。这样可以操作动态信息流中的稳定“我/发布入口”控件。未命名图片点击仍沿用严格截图检查。

草稿模式拒绝编辑页公开发布按钮；文字输入只能使用任务指定内容，且当前聚焦字段必须匹配标题或正文。保存时键盘仍显示就拒绝；原生确认弹窗只允许目标“确定”控件。确认意图已记录但结果不明时暂停核对，不自动重复提交。图库离线、图片未索引、账号不符、登录/验证码或观察不稳定均暂停接管。

暂停恢复保留任务预算、动作账本和业务进度，重新观察后继续。对本轮旧版本键盘遮挡保存指令的修复，只有明确 `reconciled=true`、旧保存已回报、旧观察显示键盘，并且尚未确认/列出草稿或发布时才允许重置保存意图；记录 `business_reconciled`。这不允许重放发布或结果未知的动作。

## 本机素材连接器

`cmd/media-connector` 在连接 USB 手机的电脑运行，用固定 ADB 路径与 serial 执行有限图库扫描和查询。通过单独 WebSocket `/device/media-connect` 复用已激活手机身份，不会覆盖 Portal 连接。服务端不需要安装 ADB。

只接收同一任务目录内、01–09 编号的 PNG/JPG 路径，不提供通用 Shell RPC。扫描后查询 MediaStore，返回真实媒体 URI，服务端核对路径与数量再开始选图。文件上传成功与图库可见是两个独立条件。[Android 官方说明](https://developer.android.com/reference/android/media/MediaScannerConnection)也说明新素材需要进入媒体索引才能被媒体应用发现。

当前 ADB 广播扫描与 `_data` 查询已在上述 Huawei 上验证。其他 Android 版本、分区存储和厂商图库需要另测；Android 执行端现已新增媒体扫描 API，工作台已接入原生索引优先、旧版 USB 兼容的能力协商，详见 [设备接入](device-setup.md)。原生扫描需使用支持该扩展的 Portal APK；能力状态以当前设备检测结果为准。当前组件不是完整 USB 手机控制器，桌面打包、驱动分发、跨平台运行仍属后续范围。

## 验证边界

历史真机验收覆盖单张图片编辑、保存草稿、草稿列表和重开字段核对；过程中发生过暂停、修复、恢复和人工收尾，不代表全程无人值守。历史记录汇总见 [验证范围](verification.md)。

公开发布、多图顺序、不同 App / Android 版本、跨账号切换和不同模型供应商需逐项验收。重开图片目前仍依赖人工核对，不做逐像素自动验证。真实账号截图、任务 ID、素材和现场日志不随源码分发。
