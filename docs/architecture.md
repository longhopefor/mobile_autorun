# 架构与执行边界

## 核心链路

```text
Vue 工作台 → Gin API → PostgreSQL + River → Eino Agent
                                         ├─ 模型 API / 本机 CLI 连接器
                                         └─ Portal WebSocket → Android
```

`cmd/server` 启动数据库迁移、管理员初始化、启动恢复、运营计划与 River worker。`internal/app` 负责应用服务；`internal/agent` 执行模型循环；`internal/device` 维护 Portal 会话及命令；`internal/business` 校验专用业务流程；`internal/store` 保存任务、事件、租约、业务记录和动作账本。

创建任务时在同一数据库事务中保存任务并使用 River `InsertTx` 入队；客户端通过幂等键避免重复创建。设备租约控制同一手机串行操作，任务保存创建时的模型快照。截图与素材保存在 `DATA_DIR`，元数据和事件保存在 PostgreSQL。

## 观察、决策与动作

每轮获取手机截图和界面树，模型只提出结构化决策。执行前再次观察；连接代次、手机状态或页面内容变化会使原决策失效。状态栏时钟、已校验输入框光标等变化有专门规则，不能将它们泛化为允许任意页面变化。

连续页面变化时有限次数重新观察与决策，仍计入预算；动作结果不明时暂停核对，不自动重发。连续重复且没有进展的动作在第 3 次提醒模型、第 6 次下发前暂停。模型完成信号只产生完成候选，成功状态由人工核验提交。

模型输入默认缩放到宽 960 px，支持 720 / 1280 px 或原图；完整原始截图与界面树用于执行校验及证据保存。模型坐标使用 0–1000 范围。缩图可减少像素数，但不保证实际模型费用下降。

初始任务决策预算为 1–100 轮，暂停且预算耗尽时可显式追加，累计最多 500 轮。模型网络、限流及部分无效结果会有限重试，每次重新观察，且不重放手机动作。任务列表归档不删除证据，不自动恢复执行。

## 连接器

- `model-connector`：在 CLI 所在电脑接收模型请求，用固定参数启动 CLI，返回受限结构化决策；不直接控制手机。
- `device-connect`：在 USB 电脑上配置 Portal，维护 `adb reverse`；也可经 ADB 一次性写入无线地址。
- `media-connector`：旧版 Portal 的 USB 图库索引兼容工具，仅处理指定任务图片路径。
- `model-probe`：读取指定 PNG 发起真实模型请求，仅返回决策，不发送手机动作。

支持 `media/index` 的 Portal 可直接扫描手机图库；该扩展 Android 工程和 APK 未包含在本仓库中。原生能力缺失与权限失败有不同处理；权限失败或索引错误不会悄悄转成成功。

## 当前限制

- 单服务实例；没有完整桌面壳、跨平台安装器或多实例恢复协调。
- 目标应用列表只是模型提示，不限制通用任务启动 / 操作其他应用；专用业务仍做账号、正文、收件人与发布核验。
- 人工继续会保留预算、业务进度和账本后重新观察，并启动新的 Agent 循环；尚未启用完整 Eino 显式中断点恢复。
- 普通文件附件传入手机，但不自动解析 PDF / Office 正文。
- 素材排版和图片合成 MP4 可本地完成；真实 AI 场景图 / 视频需要外部适配器。
- 数据包含真实手机页面，需通过部署权限、备份权限及本地忽略规则保护，见 [安全说明](../SECURITY.md)。
