## 复查与导出

```sh
make check-public
python3 scripts/check-public.py --export-dir /absolute/path/outside-project/mobile-autorun-public
```

导出目录必须在项目外且尚不存在。工具根据 Git 排除规则选取文件；已有本项目 Git 索引时也检查已跟踪文件，因此强制加入 Git 的敏感文件不会因 `.gitignore` 被漏过。导出不包含 `.git` 或旧提交历史。

确认检查通过后，在**导出目录**创建新仓库：

```sh
git init -b main
git add .
git diff --cached --stat
python3 scripts/check-public.py
git commit -m "Initial open-source release"
```

创建 GitHub 仓库后再添加自己的 remote 并推送。不要把整个工作目录直接压缩上传，也不要强制添加被忽略文件。
